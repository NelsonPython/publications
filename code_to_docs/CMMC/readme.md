## Cybersecurity Maturity Model Certification (CMMC) Compliance Templates

As a technical writer, I was tasked with writing compliance documentation for each requirement in the [CMMC Assessment Guide Level 2](https://dodcio.defense.gov/Portals/0/Documents/CMMC/AssessmentGuideL2v2.pdf).  

When I read the guide, I realized that the content had been standardized so that each section was organized first by domain and then by individual security requirements.  Furthermore, the description of each requirement contained the same elements.  This made it possible for me to write a python script to parse the content from the guide and generate templates in HTML format.  Not only did this save hours of re-typing, it ensured accuracy and completeness.

About the same time, I was working on another project called "Gearing up for Compliance".  Graphics of wheels and gears inspired this easy-to-read user interface that provides quick access to each template.

<img src="cmmc_circle.png" width="600" alt="CMMC User Interface">

Users click on a piece of the CMMC pie to drill down to a list of templates, then, click on a link to select a template.

Because the template contained precise verbiage from the guide, the team did not have to flip back and forth when questions arose about requirements.
