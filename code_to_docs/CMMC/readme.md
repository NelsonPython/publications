## Cybersecurity Maturity Model Certification (CMMC 2.0)

The CMMC Assessment Guide provided guidance for compliance with 32 CFR Part 2002, DFARS 252.204-7012, and DoDI 5200.48 in accordance with the National Institute of Standards and Technology (NIST) SP 800-171.
