# AI Prompt Engineering for Code to Docs

Software documentation for the Agentic Job Search app was generated by a Python script that sends an AI prompt to the Ollama model `qwen2.5-coder:1.5b`.  `script_name` is input at runtime.

```
    prompt = (
        f"Read the python script and write step-by-step documentation in markdown format. "
        f"The first line of your output must be the name of the script.\n\n"
        f"Script Name: {script_name}\n\n"
        f"Include code snippets for running prompts and the prompt definition"
        f"```python\n{script_content}\n```"
    )
```

# Overview:  Agentic Job Search

Agentic Job Search is an exploration of AI tools for building a code-the-docs pipeline for generating cover letters and custom resumes.

## 1. Job Description

A job description in text format is fed into the pipeline.  Job descriptions are found by using an API to download descriptions from a job board or by a simple copy-paste.  A Python script launches an AI prompt for evaluating and filtering target jobs.  Another prompt is used to summarize long job postings.  A third AI prompt is used to write a brief summary to head the custom resume and the last AI prompt generates a cover letter.

## 2. AI Prompt Templates

There is a prompt template for each section of the resume, such as Core Competencies, Education, and Professional Experience.  A Python script automates prompt generation by combining each template with the job requirements and the appropriate section of the resume.

## 3.  Gemini Prompt

Because Gemini is much more powerful that the Ollama models installed on the local virtual machine, AI compiles a special prompt to be pasted into Gemini's `Where Should We Start?` entry box.  Gemini's result is pasted into a full resume model then parsed into sections.

## 4.  Gathering Results

Outputs from each prompt are matched with sections from the full resume in order to get validated content.  The new resume content is stored in json.  Dates for professional experience are sorted and any missing dates are reported.  The final resume is converted from json to text, markdown, or Word.

## 5. Review

After human review, changes could be made directly in Word, but typing or copy-pasting is time-consuming and error-prone.  A special tool allows for adding or removing resume sections then saving changes in json.

## 6. Submit Application

Currently, the final cover letter and resume are then submitted manually.

## 7.  In Progress

In order for the pipeline to function autonomously, the AI Prompts must yield clear and consistent results that have been validated.  Currently, the AI Prompts are written in text format.  A more structured format may prevent hallucinations because the model cannot consistently differentiate requirements from resume text.  [Part 1:  Validating AI Prompts](https://github.com/NelsonPython/ai_prompts/blob/main/articles/validating_prompt_output.md) shows examples of hallucinations.
