## AI Prompt Engineering for Code-to-Docs

Models such as the Ollama model `qwen2.5-coder:1.5b` have been designed to generate code.  They can also write software user guides.  One may argue that software user guides are obsolete now that interactive AI chats that can guide developers with real-time feedback and even write code.  While this is true, in regulated environments where code can impact human safety, a software user guide may still be needed for audit and certification.  Flight control software used to fly airplanes and code used to run medical devices are two examples of safety-critical software.  

AI Prompt Engineering can speed up code to docs.  This prompt was used to draft selected software documentation for Python scripts used in the **[Agentic Job Search](overview_job_search_agentic.md)**.  Docs were processed locally by an Ollama model tailored for generating code `qwen2.5-coder:1.5b`.  

```
    prompt = (
        f"# Instructions\n"
        f"Read the Python script provided below and write comprehensive, step-by-step documentation in Markdown format.\n"
        f"- The very first line of your output must be the name of the script: {script_name}\n"
        f"- Include an overview, key functions, and code snippets describing how the script works, plus a one line instruction for running this script.\n\n"
        f"# Python Script: {script_name}\n"
        f"```python\n"
        f"{script_content}\n"
        f"```"
    )
```

## Agentic AI Code-to-Docs Pipeline

The pipeline is essentially the same as checking code into GitHub with the added benefit of auto-generated documentation.  For example, suppose you write a Python script.  `docs_gen.py` ingests a copy of your code and outputs a step-by-step user guide.  When you push changes and open a pull request, both the script and the docs will be reviewed.
