## AI Prompt Engineering for Code-to-Docs

Software documentation for **[Agentic Job Search](overview_job_search_agentic.md)** is generated automatically via this structured prompt processed by a local Ollama model, `qwen2.5-coder:1.5b`.  
```
    prompt = (
        f"Read the python script and write step-by-step documentation in markdown format. "
        f"The first line of your output must be the name of the script.\n\n"
        f"Script Name: {script_name}\n\n"
        f"Include code snippets for running prompts and the prompt definition"
        f"```python\n{script_content}\n```"
    )
```

[formulate_cover_summary.py](formulate_cover_summary.md) - writes a cover letter and a summary for the resume header

[formulate_job_desc.py](formulate_job_desc.md) - filters and summarizes a job description

## Agentic AI Code-to-Docs Pipeline

The Agentic AI code-to-docs pipeline is essentially the same as checking in code with the added benefit of auto-generated documentation.  For example, write a Python script, generate the documentation, and push changes, then open a pull request. Using the Model Context Protocol (MCP) streamlines documentation generation. 

[mcp_job_desc_client.py](mcp_job_desc_client.md) - uses MCP to send a job description to mcp_job_desc_server.py for processing

[mcp_job_desc_server.py](mcp_job_desc_server.md) - filters and summarizes a job description
